# YadiKk Framework

**A professional, modular, and highly scalable toolkit for Unity Mobile & Hyper-Casual development.**

This package contains the core logic, UI systems, and persistent data handlers designed to rapidly structure mobile Unity projects safely.

Please refer to the comprehensive markdown documentation included internally in this package.

## 🚀 Features at a Glance

*   **Game State Management:** Structured GameState transitions supporting unscaled-time pausing.
*   **UI Architecture:** Decoupled Panel, HUD, and CanvasGroup orchestrator.
*   **Persistent Data:** Seamless JSON auto-saving configuration systems.
*   **Editor Extensions:** 'SceneSwitcher' tool embedded directly in the Unity Toolbar.
*   **Haptics & Audio:** Mobile-first vibration managers mapping dynamic configurations.
