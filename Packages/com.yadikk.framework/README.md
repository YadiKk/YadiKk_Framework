# YadiKk Framework
A comprehensive toolkit for Mobile & Hyper-casual game development.

## Features
- Modular Base (Core, Audio, UI, Extensions, Utilities)
- Clean Script Architecture
- SceneSwitcher Toolbar for quick navigation

## Usage
- **Core:** Core logic and singletons.
- **Audio:** Audio manager and extensions.
- **UI:** User interfaces.
- **SceneSwitcher:** Use the Unity Toolbar drop-down to quickly switch between your enabled build scenes without losing unsaved changes.
